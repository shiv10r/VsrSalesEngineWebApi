# Deployment

The source of truth for the Render service is `deployment/render.yaml`. This file explains the choices
and lists what you must set before going live.

## Pieces

| Piece | Where | Notes |
|---|---|---|
| API + worker | Render web service | The worker runs inside the web process; a database lock keeps it safe if scaled |
| Database | Supabase PostgreSQL | Not Render's free Postgres (deleted after 30 days) |
| Timer | GitHub Actions (`.github/workflows/agent-run.yml`) | Calls `POST /api/agents/run-due` every 2 hours (optional on the always-on Starter plan) |
| Frontend | Vercel (live) / Netlify | CSP allows API calls only to the Render URL |

## Environment variables on Render

| Variable | Value | Notes |
|---|---|---|
| `ConnectionStrings__DefaultConnection` | Supabase connection string | Required, or data is lost on restart |
| `Jwt__SecretKey` | generated by `render.yaml` | The app refuses to start with a placeholder or short secret |
| `Agents__RunKey` | generated by `render.yaml` | Copy it into the GitHub secret `AGENT_RUN_KEY` |
| `Seed__AdminEmail`, `Seed__AdminPassword` | yours (password 12+ characters) | Without them no user exists outside Development |
| `AllowedOrigins` | extra frontend origins, comma separated, exact match | CORS (the production Vercel origin is built in) |
| `GooglePlaces__ApiKey` | your Google Cloud key, restricted to Places API (New) | Turns on real-time Google Maps search; empty = off |
| `GooglePlaces__DailyRequestCap` | number, default 100 | Per-day search limit; also set a Google Cloud budget alert |

Required to go live: the connection string, `Jwt__SecretKey`, and the two `Seed__Admin...` values. The rest are optional.

GitHub repository secrets: `API_BASE_URL` (no trailing slash) and `AGENT_RUN_KEY`.

## Free versus paid

- **Free plan:** the service sleeps after 15 minutes without traffic. The 2-hour timer wakes it (up to a
  minute to start) and the run keeps it awake. About 90 of the 750 free instance hours a month. GitHub
  Actions on a private repo uses about 360 of the 2,000 free minutes a month.
- **Starter plan (about $7 a month):** always on, no cold starts. Worth it once the tool earns its keep.

## Go-live checklist

1. Create the Supabase project and set the connection string on Render.
2. Deploy `deployment/render.yaml`; set the seed admin variables; confirm `GET /health` returns 200.
3. Add the GitHub secrets, then run the workflow once by hand (workflow_dispatch) and check the response.
4. Point the frontend `VITE_API_BASE_URL` at the Render URL and redeploy; check the CSP on the preview.
5. Sign in, open Agents, click "Run agents now", and watch the feed.
6. If the database already existed, the scope trim removed columns: drop `AgentRuns.DraftsReady`, `AgentSettings.DraftThreshold` and the two vendor columns on `Opportunities`, or recreate the database.
